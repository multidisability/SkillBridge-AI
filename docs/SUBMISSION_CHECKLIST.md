# Checklist submission capstone

Materi sesi 3 meminta project overview, diagram alur/workflow, konfigurasi agent dan prompt, contoh hasil, serta tautan proyek untuk jalur IBM Bob. Lengkapi hal berikut dari proses yang benar-benar dijalankan:

- [ ] Judul, masalah spesifik, pengguna sasaran, dan dampak SkillBridge AI.
- [ ] Tautan repo atau hasil build yang dapat diakses penilai.
- [ ] Diagram `docs/SDD.md` yang sudah diverifikasi terhadap aplikasi final.
- [ ] Tangkapan layar prompt IBM Bob dan minimal satu iterasi awal → revisi → hasil.
- [ ] Tangkapan layar analisis live untuk contoh profil kuat, banyak kesenjangan, dan profil ambigu.
- [ ] Ringkasan pengujian: build frontend, tes backend, dan demo dengan Gemini API key.
- [ ] Video demo singkat: masalah → input → bukti keterampilan → rencana belajar → batasan hasil.
- [ ] Penjelasan privasi: input anonim, kunci di server, dan teks diproses oleh Gemini.

Dokumen dan source code di repo merupakan bahan persiapan. Riwayat IBM Bob, keluaran Gemini live, video, dan tautan publik harus diperoleh dari penggunaan dan pengunggahan yang sebenarnya.
